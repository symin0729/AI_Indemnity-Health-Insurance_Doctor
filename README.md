# AI 실손 닥터

1~4세대 실손보험 가입자가 **"지금 보험을 유지할까, 5세대로 바꿀까"** 를 같은 의료이용 조건에서 숫자로 비교하고, 궁금한 점을 공식 자료 근거로 답하는 챗봇에게 물어볼 수 있는 반응형 모바일 웹 서비스입니다.

현재 실손보험 계약 정보, 5세대 비교 조건, 예정 치료 정보를 입력하면 구조화된 약관 Rule Set과 TypeScript 기반 결정론적 룰 엔진이 현재 계약과 5세대 전환 시나리오의 보험료, 자기부담금, 예상 보험금, 보장 제외 금액, 지급한도 초과 금액 등을 계산합니다.

> 공모전 시연용 서비스입니다. 입력 조건에서의 약관 기반 **모의 비교**이며 보험 가입·유지·전환을 권유하지 않습니다. 실제 보험금과 보험료는 보험사와 계약 약관에 따라 달라질 수 있습니다.

## 핵심 원칙

- **숫자는 AI가 아니라 규칙 엔진이 계산합니다.** AI는 설명과 질의응답만 합니다.
- 챗봇은 공식 자료에서 찾은 근거로만 답하고, 근거가 없으면 "확인되지 않습니다"로 답합니다.
- 보험 가입 권유·판매, 진단, 보험금 확정 안내는 하지 않습니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 4단계 모바일 화면 | 시작 → 입력 → 확인 → 결과 |
| 1~5세대 계산 | 삼성화재 1·2·3·4·5세대 약관을 규칙으로 구조화해 계산 |
| 유지 vs 5세대 비교 | 보험료 · 자기부담금 · 예상 보험금 · 보장 제외 · 한도 초과 |
| 손익분기점 탐색 | 통원 횟수를 늘려 가며 총부담이 역전되는 지점 탐색 |
| 계산 근거 추적 | 적용된 규칙을 Rule Trace로 표시 |
| 결과 PDF 저장 | 결과 화면을 A4 PDF로 저장 |
| 약관 근거 챗봇 | 5세대 전환 판단 질문에 공식 출처와 함께 답변 |

## 기술 스택

| 영역 | 기술 |
|---|---|
| 프론트엔드 | React, TypeScript, Vite, React Router, React Hook Form + Zod, Zustand |
| 계산 | 순수 TypeScript 함수 + `decimal.js` |
| 서버 | Vercel Functions (`api/*.ts`) |
| LLM | Google Gemini API |
| 검색(RAG) | 배포: 번들 BM25 / 개발·평가: RAGFlow |
| 테스트 | Vitest |

## 실행

```bash
npm install
npm run dev
npm test
npm run build
```

챗봇을 로컬에서 쓰려면 프로젝트 루트에 `.env.local`(git 제외)을 만들어 값을 넣습니다. 항목은 [.env.example](.env.example)을 참고하세요. **키 값은 절대 저장소에 올리지 않습니다.**

## 개인정보와 보안

### 챗봇 이용 안내 (동의창 문구)

> 입력한 일반 질문은 답변 생성을 위해 외부 AI 서비스(Google Gemini API)로 전달되며, 해외 서버에서 처리될 수 있습니다. 무료 서비스 약관에 따라 질문 내용은 Google의 서비스 개선에 사용될 수 있습니다. 이 서비스는 질문 내용을 서버에 저장하지 않습니다.
>
> 이름·연락처·병원·진단명 등 개인정보와 치료정보는 질문에 입력하지 마세요.

- **외부로 전달하지 않는 정보**: STEP 1~5의 보험 비교 입력값과 계산 결과는 챗봇으로 전달되지 않습니다. 보험료와 보장 계산은 브라우저에서 수행하며 별도 회원 DB에 저장하지 않습니다.
- **개인정보 질문 차단**: 질문 분류기가 범위 밖·개인정보 질문을 AI에 보내지 않고 고정 안내문으로 응답합니다. 질문 속 가벼운 개인 표현은 삭제 표시로 바꾼 문장만 외부로 보냅니다.
- **동의 검증**: 동의 버전이 맞지 않으면 서버가 요청을 거부합니다.
- **서버 저장 없음**: 질문 내용을 저장하지 않습니다.
- **운영 로그**: 요청마다 요청 ID, 처리 결과(ANSWERED·FALLBACK·RATE_LIMITED 등), HTTP 상태, 처리 시간만 한 줄 남기며(`api/_lib/requestLog.ts`), 질문 원문·답변·개인정보는 남기지 않습니다. 로그는 Vercel 함수 로그에 플랫폼이 정한 기간 동안 보관됩니다.

### 키와 환경변수

- 모든 비밀값(`LLM_API_KEY`, `RAGFLOW_API_KEY` 등)은 서버 함수에서만 `process.env`로 읽습니다. 비밀값에는 `VITE_` 접두어를 쓰지 않습니다.
- `.env`, `.env.local`은 `.gitignore`로 제외하고, 저장소에는 값 없는 `.env.example`만 올립니다.
- 운영 환경에서는 `CHAT_DEBUG`를 설정하지 않습니다. `CHAT_DEBUG=1`이면 응답에 내부 오류 내용이 포함됩니다.

### 호출 횟수 제한

`/api/chat`은 외부 LLM을 부르는 질문에 한해 IP당 분당 10회, 전체 하루 500회로 제한하고 초과하면 `429`를 반환합니다. 기록은 서버 함수 메모리에만 두므로 완벽한 차단이 아닌 안전망입니다. 값은 `CHAT_RATE_LIMIT_PER_MIN`, `CHAT_DAILY_LIMIT` 환경변수로 바꿀 수 있습니다.

## 알려진 한계

- Gemini 무료 한도와 간헐적 오류로 시연 중 답변이 실패할 수 있으며, 이때는 고정 안내문을 보여 줍니다.
- 계산 규칙은 AI 원문 검증까지 마친 "초안 검산" 상태로, 확정 보험금이 아닙니다.
- 챗봇은 상품 필터 없이 동작해 삼성 외 상품을 구분하지 못하며, 1·2세대 약관은 검색 자료에 없습니다.

## Health API 상태 계약

`GET /api/health`는 비밀값을 노출하지 않고 API와 외부 서비스의 설정 상태만 반환합니다.

- `status`: RAG와 LLM이 모두 설정되면 `ready`, 하나라도 설정되지 않으면 `degraded`
- `services.api`: API가 응답하면 `available`
- `services.rag`, `services.llm`: 필수 환경변수 유무에 따라 `configured` 또는 `unconfigured`

`not_configured`, `ok`, `error`는 이 API의 상태값으로 사용하지 않습니다.
