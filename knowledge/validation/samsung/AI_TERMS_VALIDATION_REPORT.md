# 삼성화재 실손 1~5세대 AI 약관 검증 보고서

## 판정

- 검증 상태: `AI_VALIDATED_WITH_CORRECTIONS`
- 공식 PDF: 5개
- 검증 방법: PDF 페이지별 원문을 추출하여 Rule의 산식, 정액·정률 공제, 지급한도, 횟수 및 특약 구조를 대조
- 운영 계산 활성화: `false`
- 1세대 상태: 원문·엔진 검증 완료, RAGFlow 실행 평가 대기
- 2세대 상태: 표준형·선택형Ⅱ 원문·엔진 검증 완료, RAGFlow 실행 평가 대기
- 3세대 상태: 표준형·선택형Ⅱ 기본형과 3대 비급여 특약 원문·엔진 검증 완료, RAGFlow 실행 평가 대기
- 4세대 상태: 급여·일반 비급여·3대 비급여 원문·엔진 검증 완료, RAGFlow 실행 평가 대기
- 5세대 상태: 일반형 G5-01~09와 계약전환형 G5-CONV-01~09의 독립 RuleSet·엔진 검증 완료, RAGFlow 실행 평가 대기

AI 원문 대조 결과, 기존 32개 Rule 중 핵심 구조가 맞는 항목은 유지하고 범위가 불완전한 8개 Rule을 보완했다. 기존 목록에서 빠진 담보 6개를 추가하여 현재 Rule 후보는 38개다.

## 수정한 핵심 사항

1. 2세대 표준형·선택형Ⅱ 입원 산식에 상급병실료 차액 50%와 1일 평균 10만원 한도를 추가했다.
2. 2세대 선택형Ⅱ 처방조제비를 외래와 분리했다.
3. 3세대 표준형 기본형 입원·외래·처방조제비 Rule을 추가했다.
4. 3세대 선택형Ⅱ 기본형의 입원 범위를 명확히 하고 외래·처방조제비 Rule을 추가했다.
5. 4세대 도수·체외충격파·증식치료에 최초 10회 이후 증상 개선 확인 조건을 추가했다.
6. 5세대 중증·비중증 비급여 입원에 상급병실료 차액 계산을 추가했다.
7. 5세대 중증 근골격계 치료에 최초 10회 이후 증상 개선 확인 조건을 추가했다.
8. 5세대 비중증 비급여 보험료 차등의 직전 12개월 평가기간, 지급액 구간 및 100%·200%·300%·400% 요율상대도를 구체화했다.

## 원문에서 확인한 주요 예외

- 국민건강보험·의료급여 미적용 시 별도 40% 보상 규정이 존재하는 세대가 있다.
- 1세대와 일부 세대는 다수 보험계약 가입 시 실제 발생 의료비를 넘지 않도록 비례보상한다.
- 3세대 기본형에서는 선택계약이 보장하는 3대 비급여 의료비를 기본형 보상에서 제외한다.
- 4·5세대 도수·근골격계 관련 치료는 단순 연 50회가 아니라 최초 10회 이후 객관적 개선 확인 조건이 붙는다.
- 5세대 비중증 비급여 통원은 상해·질병 각각 연 100일이며, 계약 종료 후 추가 보상에는 별도 180일·90일 조건이 있다.
- 특약 미가입, 보상 제외 의료비, 연간 한도·횟수 소진 여부가 확인되지 않으면 계산 결과를 확정할 수 없다.

## 사용 제한

이 결과는 AI가 공식 약관 원문과 구조적으로 대조한 검증 기록이다. 사용자가 손계산이나 약관 해석을 직접 담당하지 않으며, 원문만으로 확정할 수 없는 항목은 필요한 추가 자료와 확인 방법을 기록한다. 실제 보험금 지급 결정을 대신하지는 않는다. 원문·자동 경계값·RAG 검색 검증이 끝날 때까지 `calculationEnabled`는 `false`로 유지한다.
