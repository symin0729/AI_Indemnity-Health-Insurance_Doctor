- 원문 버전: 검증 완료
- 핵심 산식: 검증 완료
- 한도·기간·비건보 분기: 엔진 반영 및 자동 테스트 완료
- 면책 처리: 사실관계 확인 전 계산 차단
- 정제 추출문: 워터마크 및 반복 글자 미포함 확인
- RAGFlow 실행 평가: 대기
- 운영 계산: 비활성화 유지

## 원문 근거

- PDF 97~99쪽: 상해 D1 입원·통원 산식, 5천만원·10만원 한도, 365일·30일, 비건보 40%, 다수계약 비례보상
- PDF 100~102쪽: 상해 D1 보상하지 않는 손해와 비용
- PDF 112~115쪽: 질병 D1 입원·통원 산식, 5천만원, 365일·180일 재보장, 다수계약 비례보상
- PDF 115~117쪽: 질병 D1 보상하지 않는 손해·상병·비용

## 자동 계산 안전장치

- D1 특약 가입 미확인 시 `CONFIRMATION_REQUIRED`
- 면책 해당 여부 미확인 시 `CONFIRMATION_REQUIRED`
- 국민건강보험 적용 여부 미입력 시 `CONFIRMATION_REQUIRED`
- 비건보 입원은 발생 의료비 총액의 40% 적용
- 상해·질병 입원 5천만원 누적 한도 적용
- 상해 통원 5천원 공제, 1일 10만원, 365일 이내 30일 적용
- 질병 입원 365일 초과 시 최종 퇴원 후 180일 경과 여부 확인
- 다수계약은 0~1 사이의 비례보상 계수가 있을 때만 적용

## 실제 청구 시 필요한 자료

상품 Rule 검증을 위한 추가 자료는 현재 없다. 다만 특정 계약의 보험금을 계산할 때는 다음 자료가 필요하다.

- 보험증권 또는 가입증서: D1 특약 가입·가입금액 확인
- 진료비 영수증·세부내역서: 급여·비급여·실제부담액 확인
- 입·통원 날짜와 퇴원일: 365일·30일·180일 조건 확인
- 병실 내역: 기준병실·실제 병실 차액 확인
- 다른 실손보험 가입·지급 내역: 비례보상 확인
